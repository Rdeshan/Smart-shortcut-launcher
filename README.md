# Shortcut Launcher

Boost your productivity with global keyboard shortcuts for your favorite applications.

## Features

- ⚡ Launch any application with a custom keyboard shortcut
- 🎯 Support for single keys and chord combinations
- 🔄 Auto-updates to keep you on the latest version
- 🎨 Beautiful, modern interface
- 🚀 Starts automatically with Windows

## Getting Started

1. Launch Shortcut Launcher
2. Click **Browse…** to select an application
3. Enter your desired key combination (e.g., `Ctrl+Shift+N`)
4. Click **Add** to save

## Shortcut Examples

- `Ctrl+Shift+N` - Open Notepad
- `Alt+B` - Open Browser
- `Ctrl+Alt+C` - Open Calculator
- `Alt+V+S` - Chord: Press Alt+V, then S
