Shortcut Manager

Create, edit, and manage global keyboard shortcuts.

💡 Tip: Use Alt or Ctrl+Alt combinations (e.g., Alt+G+O, Ctrl+Alt+N). Avoid Ctrl alone - it conflicts with Windows and IDEs (VS Code, IntelliJ, etc.). Important: Don't use same starting keys (Alt+G+O and Alt+G+H won't work together).

👋 Welcome to Shortcut Launcher!

Get started by creating your first shortcut:

  1. Click Browse… to select an application or file
  2. Or click Add URL/Command to enter a website or command
  3. Enter a key combination (e.g., Ctrl+Shift+N)
  4. Click Add to save your shortcut
